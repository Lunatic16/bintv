TiviMate setup
  1. Settings → Playlists → Add playlist → M3U playlist.
  2. Paste the playlist URL above.
  3. For EPG, use the matching /epg/….xml URL (TiviMate fills this from the playlist when supported).
  4. Set Playlist update interval to the shortest option — the Events playlist regenerates on every request, so new events appear automatically.
